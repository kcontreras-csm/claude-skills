# Hello Skill

This is an example Claude Code skill published through Satellite's skills store. Replace it with your own:
each skill is a folder with a `SKILL.md` (the frontmatter above gives its name, description and version) plus
any files it needs. See `reference/example.md` for how extra files travel with a skill.

When invoked, greet the user and point them at `Settings > Skills` in Satellite.
